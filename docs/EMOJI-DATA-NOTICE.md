# Unicode Emoji data

The IPA build downloads the pinned Unicode Emoji 18.0 `emoji-test.txt` source from https://www.unicode.org/Public/18.0.0/emoji/emoji-test.txt, and generates a compact catalogue of fully-qualified entries in CLDR keyboard order. Unicode data are subject to the Unicode License V3: https://www.unicode.org/license.txt. The keyboard searches its bundled file offline. Rendering depends on the host iOS font and may not include newly standardized glyphs.
